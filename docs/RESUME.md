# 简历项目表述(ReflexRAG)

> 用法:按目标岗位挑 3-4 条,量化数字来自 data/eval_reports/20261008-172735,
> 面试必须能现场复跑 `python scripts/run_eval.py` 并解释每个数字。

## 项目一句话

**ReflexRAG — 自适应反思式法律问答系统**(独立开发,Python/FastAPI/Qdrant)
Agent 自主决策检索策略(免检索直答/单跳/多跳分解/拒答),证据不足自我纠正补检,
答案逐句可溯源到法条,配套自动化评测流水线。

## 简历 bullet(可组合)

- 设计并实现自适应查询路由 Agent:一次 LLM 调用完成意图分类、指代消解与
  多跳查询分解,四路决策(直答/单跳/多跳/拒答)使**路由准确率较无路由基线
  提升 48pp(27%→75%),超范围拒答正确率 100%**,免检索路径使 p50 延迟
  由 4.2s 降至 2.3s;
- 实现证据充分性自反思循环:LLM 判定检索证据是否覆盖问题要点,缺口驱动
  补充查询迭代检索,检索轮数随问题难度自适应(平均 1.02 轮);
- 构建混合检索管线:结构感知分块(法条原子级,207 块)+ BM25(jieba)
  与向量检索(Qdrant)双路召回 + RRF 排名融合,金标集 recall@8 达 0.91;
- 建立两级答案校验:引用编号越界由代码确定性拦截并触发重生成,陈述忠实性
  由 LLM 审查,端到端忠实性评分较朴素 RAG 提升 32%(2.62→3.45/5);
- 自建 73 题金标评测集与自动化评测流水线(检索指标纯代码计算 + LLM-as-judge),
  完成朴素 RAG→混合检索→完整系统的消融实验,量化各模块贡献;
- 工程化:SSE 流式输出与 Agent 思考过程可视化、全链路 Trace(token/延迟
  逐阶段统计)、评测断点续跑与错误样本隔离、Docker Compose 部署、CI(Lint+测试)。

## 面试 30 秒电梯陈述

"我做了一个劳动法领域的 Agentic RAG 问答系统。核心思路是让 Agent 自己决定
'何时检索、怎么检索':简单题单轮检索,复杂题自动拆解成子查询多跳迭代,
证据不足会自我纠正地补检索,闲聊和超范围问题直接免检索处理。每个答案
逐句带法条引用,引用越界由代码拦截、忠实性由 LLM 复查。我给它建了 73 题
金标集和自动化评测流水线,消融实验显示路由模块让拒答正确率到 100%、
忠实性提升 32%,而且平均延迟反而更低。"
